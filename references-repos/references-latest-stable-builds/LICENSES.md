## Redistribution notes

Kobo's complete GPLv3 text is already included in its `LICENSE`. Preserve that
file and the original notices when redistributing its source. The copyright
line for the Free Software Foundation in that file concerns the license text;
it is not an attribution for the plugin's code.

Meguru's `libs/` contains compiled `.so` libraries. Before redistributing those
binaries, verify that recipients can obtain the complete corresponding source,
including the scripts needed to build them, under GPLv3 section 6. The bundled
README identifies upstream version 0.0.12, but that reference alone does not
establish that the complete matching source and a compliant delivery method are
available. This index does not certify that requirement as satisfied.

Keeping independent projects together as references does not by itself change
their licenses. Copying or adapting their code into another project requires a
separate review of the applicable license terms.
