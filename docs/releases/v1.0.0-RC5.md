# Panels+ | Performance Update

Built from tag: `v1.0.0-RC5`

This release focuses on speed and on pages the panel detector used to miss. Opening panel view no longer stalls for seconds, swiping between panels is smoother, and panels are now found on dark-background pages and in rows of small panels where detection previously gave up.

## Highlights

<div align="center">

| Feature | Description |
| :---: | :--- |
| **Feature 1** | **Panel detection on dark pages**<br><br>KOReader's detector recognizes panels by looking for *white* gaps between them, so a page printed white-on-black had nothing it could find. Panels+ now measures the page's own background colour and works from that instead, so an inverted page is detected exactly like a normal one. |
| **Feature 2** | **Much faster panel detection**<br><br>Opening panel view used to rasterize the whole page at full resolution up to 29 times, once per probe point, which is where the multi-second wait came from. Detection is now a single reduced-size render, and the fallback path reuses one rasterization for every probe instead of one each. |
| **Feature 3** | **Smoother panel switching**<br><br>Every panel switch used to force a full garbage collection, which stalled the UI for longer than it reclaimed. That is gone, and the next panel is now rendered in the background while you read the current one, so swiping to it is instant. Pre-rendering switches itself off when the device is low on memory. |
| **Feature 4** | **Choose your detector**<br><br>A new *Panel detection* menu lets you pick **Auto**, **Gutter mode**, or **Outline mode**, so a page that either one mishandles can be worked around on the spot. Gutter mode always uses the quick, gap-based detector; Outline mode always uses KOReader's own, more literal detector; Auto tries Gutter first and falls back to Outline. The mode can also be cycled from the panel viewer itself with a button. Alongside the menu are toggles for panel pre-rendering and for writing detection timings to the log. |

</div>

## Fixes

- Rows of small panels separated by narrow gutters are now split into individual panels instead of being returned as one. The minimum detectable gutter went from roughly 15px to roughly 7px on a 1600px-wide page.
- Panel detection no longer re-rasterizes the full page for every probe point.
- Removed the forced garbage collection that ran on every panel switch.
- Prefetch jobs scheduled for pages you have already turned past are now cancelled instead of all running anyway, and no scheduled work survives closing the document.
- The panel cache holds 12 pages instead of 2, so stepping back a page no longer re-detects it from scratch.
- Fixed the low-memory check for pre-rendering, which compared bytes against a kilobyte threshold and so never actually triggered.
- Colour pages are now converted once before scanning rather than being read pixel by pixel through the slow path.

## Notes

- Panels that share a border line with no background gap between them cannot be separated: there is no empty band to split on, and KOReader's own detector cannot separate them either.
- Interlocking and diagonal panel layouts fall back to KOReader's detector, since a straight cut cannot express them.

## Upgrading

Copy `panels_plus.koplugin` over your existing folder and restart KOReader. Your settings are kept; the detector and cache values tuned in this release are applied automatically.
